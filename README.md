# Proyecto Front-End

Este proyecto corresponde al Aprendizaje Esperado N°7 del módulo de Desarrollo Front-End.
El objetivo es aplicar control de versiones utilizando Git y GitHub, simulando un flujo de trabajo colaborativo.

## Funcionalidades implementadas
- Estructura base del proyecto con archivo index.html.
- Implementación de una barra de navegación básica en el sitio.
- Implementación de un footer básico como mejora visual.

## Ramas utilizadas
- **master**: rama principal del proyecto.
- **feature/navbar**: rama utilizada para agregar la barra de navegación.
- **feature/footer**: rama utilizada para simular un Pull Request y flujo de revisión en GitHub.

## Flujo de trabajo
- Creación de ramas de funcionalidad.
- Realización de commits por funcionalidad.
- Push de ramas al repositorio remoto.
- Creación, revisión y aceptación de Pull Requests en GitHub.
